# Freezer Retrofit ROI Dashboard

A financial ROI and cash flow model evaluating a 5-year commercial freezer retrofit project.

## Project Overview
* **Objective:** Evaluate the 5-year financial feasibility and return on investment (ROI) for a capital expenditure project involving commercial freezer system retrofits, incorporating energy efficiency gains and reduced inventory spoilage.
* **Tools Used:** Power BI Desktop, Data Modeling, DAX Measures, Relational Data Structuring.

## Key Metrics & Financial Scope
* **Initial Outlay:** ($210,000) capital investment at Year 0.
* **Net Cash Flow:** $151,250 cumulative net return over the project lifecycle.
* **Energy Savings:** $281,250 achieved through high-efficiency compressor upgrades.
* **Spoilage Savings:** $100,000 recovered from enhanced temperature monitoring and reliability.

## Key Technical Highlights
* Engineered a dynamic multi-year chronological column chart tracking cash flow turns from Year 0 baseline investment through Year 5 payback.
* Configured custom scalar KPI cards with explicit integer un-rounding and localized currency formatting to present precise financial figures to stakeholders.
* Structured relational financial data to ensure real-time metric updates across all visual elements without relying on static text or manual edits.
